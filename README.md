# Панель УООЗД — реестр закупок

Веб-панель для управления организационного обеспечения закупочной деятельности (223-ФЗ):
реестры трёх отделов (ОАО, ОПАиЗ, ОВРК), автоматический разбор извещений, протоколов,
договоров и платёжек из файлов **docx / doc / pdf / xlsx / xml**, аналитика, отчёты,
контроль сроков и проверка СМП.

Лицензия: [Apache License 2.0](LICENSE). Язык проекта — русский.

## Возможности

- **ОАО** — реестр закупок по годам, «Мой день», приём извещений/протоколов/договоров
  перетаскиванием файла на страницу («было → станет», защита от дублей), формирование
  извещений и протоколов по шаблонам, история изменений, уведомления.
- **ОПАиЗ** — электронные заявки (связь с реестром ОАО по № 1С и НМЦК), СЗ 1С, запросы КП,
  договоры ЕП, счета, проверка СМП по перечню, сквозная аналитика по позициям.
- **ОВРК** — реестр контрактов: исполнительные документы (УПД/акты), платёжки,
  автоматическая сверка с выгрузкой 1С, контроль сроков размещения в ЕИС, доп. соглашения,
  претензии, поиск ошибок в платёжках.
- **Вход по логину и паролю** — PBKDF2-HMAC-SHA256 (210 000 итераций), блокировка после
  5 неудачных попыток, сессии по хэшу токена, роли и права по отделам.
- **Хранение в MySQL 8.0** — схема `mysql/schema.sql` (27 таблиц), слой доступа
  `modules/db.py`, миграция из Excel/JSON — `modules/migrate_excel_to_mysql.py`.
- **Импорт XML** — извещения и протоколы 223-ФЗ, табличный XML; защита от XXE.
- **База знаний** — раздел панели `/baza-znaniy` с форматами всех принимаемых файлов.

## Быстрый старт (демо)

```bat
pip install openpyxl python-docx pypdf "docxtpl[subdoc]" xlrd
python demo\демо.py        :: соберёт демо-реестр и откроет http://localhost:8090
```

Все суммы, предметы и участники демо вымышленные. Сценарий показа — `docs/Сценарий показа.txt`.

## Хранилище MySQL

```sql
SOURCE mysql/schema.sql;          -- база uoozd, 27 таблиц
```

```bash
pip install pymysql cryptography
set UOOZD_DB_PASSWORD=...
python modules\migrate_excel_to_mysql.py --config config.ini --panel "Демо-реестр" --dry-run
python modules\migrate_excel_to_mysql.py --config config.ini --panel "Демо-реестр"
```

Образец конфигурации — `config.example.ini`. План переезда с файлов на MySQL без остановки
работы — `docs/ARCHITECTURE.md`.

## Структура

| Папка | Содержимое |
|---|---|
| `server/` | веб-панель: `reestr_server.py` (backend + UI), `start_demo.py`, база знаний |
| `demo/` | генератор демо-реестра (`демо.py`) и ярлыки запуска |
| `modules/` | слой MySQL (`db.py`), вход и сессии (`auth_mysql.py`), импорт XML (`xml_import.py`), миграция |
| `mysql/` | схема БД `schema.sql` |
| `module_izveschenie/` | модуль «Подготовка извещения» (ядро, справочники, шаблоны) |
| `samples/` | образцы XML (извещение, протокол, таблица, XXE-тест) |
| `docs/` | архитектура, аудит ИБ, форматы файлов, подключение 1С, инструкция для ИТ, сценарий показа |

## Безопасность

Аудит текущего решения и чек-лист мер — `docs/SECURITY_AUDIT.md`. Кратко:
TLS через reverse-proxy, обязательный вход (`ВХОД_ПО_ПАРОЛЮ = True`), пароль ≥ 10 знаков,
блокировка подбора, журнал попыток входа, заголовки безопасности, нейтральные ошибки
клиенту, append-only журнал (у приложения нет DELETE на `audit_log`).

## Форматы файлов

Полное описание форматов входных файлов (заявка 1С, реестр, извещение, протокол, договор,
платёжка, таблицы обмена, три XML-формата) — `docs/Форматы файлов.md` и раздел
«База знаний» в самой панели.

## Подключение к 1С

Два механизма: OData (веб-публикация, рекомендуется) и прямое COM-соединение
(V83.COMConnector, без публикации). Требования к базе 1С — `docs/Подключение 1С.md`;
пошаговая настройка COM для ИТ и администратора 1С —
`docs/Инструкция для ИТ — COM-подключение 1С.md`.
