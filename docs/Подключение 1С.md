# Подключение панели к 1С: что должно быть настроено в базе 1С

Версия 1.0 · 14.10.2026

Панель поддерживает два механизма обмена с 1С. Этот документ — чек-лист для
администратора 1С: что включить в базе и на сервере, чтобы каждый из них заработал.

---

## Вариант 1. OData (веб-публикация) — рекомендуемый

Панель читает данные по стандартному интерфейсу OData (`/odata/standard.odata`)
или через HTTP-сервис расширения (`/hs/odata`). Данные только читаются.

### В конфигураторе / консоли «Администрирование»

1. **Публикация на веб-сервере** (IIS или Apache 2.2/2.4 с модулем 1С `wsap24.dll`/`mod_1c`):
   - Администрирование → Публикация на веб-сервере → опубликовать базу;
   - включить флажок **«Публиковать стандартный интерфейс OData»**;
   - в списке объектов отметить **только те таблицы**, которые реально нужны панели
     (принцип минимальных прав): документы закупок, справочники контрагентов/номенклатуры и т.п.
2. **Пользователь 1С** для панели:
   - отдельная учётная запись, не администратор;
   - права **только на чтение** опубликованных объектов;
   - аутентификация — обычная (логин/пароль 1С); в панели она передаётся как HTTP Basic.
3. **Адрес публикации** для панели:
   `http://<сервер>/<имя публикации>/odata/standard.odata/` — именно с завершающим
   `odata/standard.odata/`; панель сама не дописывает этот путь.
4. Для `https://` — действующий сертификат. Флажок «не проверять сертификат» в панели
   предназначен только для тестовых контуров с самоподписанными сертификатами.

### Проверка со стороны 1С

Открыть в браузере `http://<сервер>/<база>/odata/standard.odata/$metadata?format=atom`
под пользователем панели — должен вернуться XML со списком наборов данных.

## Вариант 2. Прямое COM-соединение (без веб-публикации)

Панель подключается через COM-соединитель 1С (`V83.COMConnector`) и вызывает
экспортную функцию общего модуля. Подходит, когда публиковать базу нельзя.

### На сервере панели (Windows)

1. Установлена **платформа 1С той же разрядности, что и Python** (64-бит Python →
   64-бит 1С) и зарегистрирована `comcntr.dll` (ставится с платформой).
2. `pip install pywin32` — без него раздел работает только как справочник параметров.
3. Учётная запись Windows, под которой работает панель, должна иметь право
   запускать COM-объект V83.COMConnector и читать каталог файловой базы
   (для файлового варианта).
4. **Лицензия 1С**: COM-подключение занимает клиентскую лицензию на сервере панели.

### В конфигурации 1С (доработка базы)

1. **Пользователь 1С** для панели: отдельная учётная запись с минимально нужными
   правами (чтение нужных объектов + право на внешнее соединение).
2. **Общий модуль** (например, `УООЗД_Интеграция`) с флагами:
   - **Сервер** — да;
   - **Внешнее соединение** — да (без него модуль недоступен через COM);
   - «Вызов сервера» и клиентские флаги — по необходимости, панели они не нужны;
   - **Привилегированный режим** — только если без него никак: модуль выполняется
     с полными правами, тогда проверки прав нужно делать в коде самой функции.
3. В модуле — **экспортные функции** (`Функция Имя(Параметр) Экспорт`), например:

   ```bsl
   Функция ПроверитьСвязь(Параметр) Экспорт
       Возврат "ОК: " + ТекущаяДатаСеанса();
   КонецФункции

   Функция РеестрЗакупок(Параметр) Экспорт
       // ... запрос к данным, формирование структуры ...
       Запись = Новый ЗаписьJSON;
       Запись.УстановитьСтроку();
       ЗаписатьJSON(Запись, Результат);
       Возврат Запись.Закрыть();   // отдаём JSON-строкой — панель сама разберёт
   КонецФункции
   ```

4. **Возвращаемое значение** — строка (лучше всего JSON через `ЗаписатьJSON`),
   число или булево. Объекты 1С (ТаблицаЗначений, ссылки) через COM в Python
   не сериализуются — сериализуйте в JSON на стороне 1С.
5. Параметр — одна строка (можно JSON-строку со структурой запроса); если параметр
   не нужен, объявите функцию без параметров.

### Строка соединения (формат V83.COMConnector)

```
файловая база:        File="C:\Базы\Закупки";Usr="Имя";Pwd="пароль";
клиент-серверная:     Srvr="srv1c:1541";Ref="ИмяБазы";Usr="Имя";Pwd="пароль";
```

Параметры через `;`, значения в кавычках, в конце — `;`. Пароль в форме панели
задаётся отдельным полем и в строке не хранится.

## Сравнение вариантов

| | OData | COM |
|---|---|---|
| Доработка базы | публикация, без кода | общий модуль с экспортными функциями |
| Где работает панель | любая ОС | только Windows + платформа 1С + pywin32 |
| Лицензия 1С | не занимается | занимает клиентскую лицензию |
| Чтение произвольных таблиц | да (по $metadata) | только то, что отдают функции модуля |
| Запуск кода в 1С | нет | да (экспортные функции модуля) |
| Производительность на больших выборках | средняя (HTTP+JSON) | выше, но держит сеанс 1С |
